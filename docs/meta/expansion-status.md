# Expansion of the citation analysis

The manuscript now includes four completed studies. Its [main pooled specification](assessments.md) reports the generated count of
original papers contributing to proportional estimates. This is not
the number of records in the source inventories, which include repeated assessments,
unclear classifications and papers without an analyzed disclosure event.

| Source | Evidence preserved | Citation-analysis status |
| --- | --- | --- |
| Nieuwenhuis | 157 classified originals; 153 historical analysis papers | Completed; same-paper Web of Science, OpenAlex and OpenCitations comparisons |
| Lal | All 67 assessed political-science papers | Completed; alternative diagnostics substitute for one another |
| Lazic | All 200 deposited animal-study assessments | Completed; 135 classified papers after earlier-publicity exclusion; proportional fitting additionally omits all-zero histories |
| Psychology replication project | 100 completed replications of 98 originals | Completed; 59 unsuccessful and 39 successful judgments; external matches and synthetic controls |
| I4R | Source reports and paper-specific assessment/disclosure ledgers | Three selected matched cases; excluded from pooling |
| Hainmueller–Mummolo–Xu | 46 interaction assessments in 22 originals | Original DOIs and early versus final audit rosters require linkage; no citation effect estimated |
| Chiu and colleagues' panel audit | 49 reanalyzed papers and detailed supplements | Original identities, first-release roster and diagnostic definitions require verification; no citation effect estimated |
| Cancer replication project | 53 roster papers; 188 result rows from 23 assessed papers | Report dates and multiple-result aggregation require resolution; no citation effect estimated |
| SCORE replication | 164 original papers; 274 assessments | Earlier report dates require verification; 2026 summary is beyond current 2025 citation cutoff |
| SCORE reproduction | 600 roster papers; 143 assessed papers | Earlier report dates require verification; no citation effect estimated |
| Multi100 | 100 original papers; 509 analyst assessments | Paper-level assessment rule and pre-2026 release timing remain unresolved |
| Mediation audit | 174 source paper records | Original identity crosswalk unresolved; no citation effect estimated |
| FLoRA/FReD | Full frozen inventories and original assessment records | Discovery and source-review material; overlapping papers cannot be summed as independent cohorts |
| Statcheck | 50,845 original DOI records; 688,112 extracted tests | Flags are retained; public report dates and consequential-error verification remain unresolved |

The next methodological-audit work is the interaction and panel cohorts: resolve
original identities, establish which papers appeared in the earliest public report,
freeze the assessment rule, and run the citation pipeline. This adds information
about publicized methodological problems without treating inventories as completed
causal studies. The broader project remains in progress.
