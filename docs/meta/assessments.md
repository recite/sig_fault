# Citation changes after methodological criticism

Four audits contribute 367 papers to the main proportional synthesis.
Psychology replication outcomes are analyzed separately and are not pooled here.

| Audit | Flagged / comparison | Change, % [95% interval] | Weight, % |
| --- | ---: | ---: | ---: |
| Neuroscience | 76 / 77 | -14.1 [-32.8, 9.7] | 33.6 |
| Instrumental variables | 8 / 59 | -14.5 [-36.0, 14.2] | 24.5 |
| Animal studies | 82 / 45 | -7.2 [-29.4, 21.9] | 27.0 |
| Interaction models | 13 / 7 | -17.3 [-43.9, 22.0] | 14.9 |
| Precision-weighted mean |  | -12.9 [-24.3, 0.2] | 100.0 |

Substituting the IV inferential-sensitivity diagnostic gives -4.5% [-17.0, 9.9]%.
The primary REML sensitivity with modified Knapp–Hartung uncertainty gives -12.9% [-30.7, 9.4]%.

These summarize selected audits, not a universal effect of publicizing errors.
The assessments, document-type coverage and prior draft circulation differ across audits.
Continued citation can coexist with a relative citation penalty.
