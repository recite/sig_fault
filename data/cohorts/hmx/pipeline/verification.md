# Verification of the interaction-audit analysis

The public annual panel was independently reconstructed from all 5,500 frozen
citation-link records. All 440 paper-year counts matched. Re-aggregating the source
assessments reproduced all 66 paper-by-diagnostic labels, including unknown tests.
Publisher metadata verifies all 22 original identities; the version-one archive
preserves the earlier public roster.

The primary log ratio and eight unadjusted specification coefficients agree with
direct calculations from group totals. A separate dummy-variable Poisson model and
cluster sandwich reproduce the primary coefficient and its standard error. An
independent conditional-binomial calculation reproduces the journal/year-adjusted
coefficient and standard error. Independent paired article resampling reproduces
the primary and nonoverlap bootstrap standard errors and percentile intervals.

Williams (2011) has zero article/review citations in both selected years. Descriptive
samples therefore contain 22 originals (21 excluding Vernby), while the Poisson
coefficients use 21 (20 excluding Vernby). Vernby appears in both the interaction
and IV audits and is retained only in the latter pooled component.

Huddy, Mason and Aarøe (2015), a comparison paper, rises from 34 to 60 citations.
Omitting it reverses the proportional contrast's sign. Comparison medians fall
while flagged medians rise, and an earlier negative relative-growth contrast
precedes formal publication. The report therefore describes a sensitive mean-growth
comparison around additional publicity, not an established publication-induced
break or a typical-paper citation decline. The source diagnostic is not a verified
refutation of each original substantive conclusion.

The pre-publication baseline parameter in the shared model has a calendar-shift
regression test; its default preserves the existing neuroscience estimates. The
shared citation-code refactor reproduces all existing psychology numerical outputs.
The public analysis and acquisition receipt chains are separate: estimation needs
only public frozen files, while verification of raw downloads needs the saved cache.

The mechanical data audit found no duplicate paper-year keys, missing outcomes or
invalid ranges. Citation distributions are skewed; the means, medians, bootstrap
and leave-one-out results address that directly. The audit paper's own citations
are dated 2018 for all originals, so they fall in the omitted event year. The
manuscript provenance scan's apparent near-match is a LaTeX widow-penalty setting
of 10,000 versus a 9,999-draw bootstrap, not an analytical discrepancy.
